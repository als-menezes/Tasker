# TaskFlow

TaskFlow é uma aplicação full-stack de gerenciamento de tarefas.

O projeto está sendo desenvolvido com React no frontend e Node.js/Express no backend.

## Tecnologias

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Node.js
- Express
- CORS
- dotenv

## Funcionalidades

Atualmente o projeto possui:

- Estrutura frontend/backend
- API REST inicial
- Comunicação entre React e Express

## Como executar

### Backend

```bash
cd backend
npm install
npm run dev
