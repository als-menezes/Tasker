# Tasker

Tasker é uma aplicação full-stack de gerenciamento de tarefas.

O projeto está sendo desenvolvido com React no frontend e Node.js/Express no backend.

## Tecnologias

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Node.js
- Express
- CORS
- dotenv

## Funcionalidades

- [x] Estrutura frontend/backend
- [x] API REST inicial
- [x] Comunicação entre React e Express
- [x] PostgreSQL
- [x] Cadastro de usuários
- [x] Hash de senhas com bcrypt
- [x] Login
- [x] Autenticação JWT
- [x] Rotas protegidas
- [x] CRUD de tarefas
- [ ] Dashboard
- [ ] Filtros
- [ ] Responsividade
- [ ] Testes
- [ ] Docker
- [ ] Deploy

### Backend

cd backend
